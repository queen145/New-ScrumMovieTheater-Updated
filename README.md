\## 📌 About the Project



ScrumMovieTheater is a full-stack movie theater web application developed as a \*\*group project\*\* using ASP.NET Core and C#.



The application allows users to browse movies and showtimes, while administrators can manage movies, theaters, auditoriums, and showtimes.



The project was developed collaboratively using an Agile/Scrum approach, with team members contributing to different areas of the application.

\## 🐳 Docker



The application was containerized using \*\*Docker\*\* to provide a consistent environment for building and running the ASP.NET Core application.



The repository includes a `Dockerfile` that:



\* Uses the .NET 10 SDK image to build the application

\* Publishes the ASP.NET Core application

\* Uses the .NET 10 ASP.NET runtime image

\* Configures the application to run on port `8080`

\* Exposes port `8080`

\* Runs the application inside a Docker container



The Docker image was also used as part of the Azure deployment process.



\## ☁️ Azure Deployment



The application was deployed as a containerized application using \*\*Microsoft Azure Container Apps\*\*.



The deployment process included:



1\. Building the ASP.NET Core application

2\. Creating and testing the Docker image

3\. Publishing the Docker image to Azure Container Registry

4\. Deploying the container to Azure Container Apps

5\. Configuring the application to run on port `8080`

6\. Troubleshooting container and deployment configuration issues



The Azure deployment was used as part of the project demonstration. The cloud resources may not remain active after the project period.
